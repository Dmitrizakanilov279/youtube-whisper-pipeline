# YouTube Video Transcription Pipeline with OpenAI Whisper

Automated end-to-end speech-to-text data pipeline leveraging OpenAI Whisper for YouTube video transcription, NLP processing, and multilingual text extraction.

## Key Features
- **Automated Audio Extraction**: Downloads and isolates high-quality audio streams directly from YouTube URLs.
- **Speech-to-Text Transcription**: Leverages OpenAI's Whisper model for precise multilingual speech recognition.
- **Flexible Output**: Generates clean transcriptions ready for NLP analysis, indexing, or documentation.

## Tech Stack
- **Language**: Python 3.x
- **AI/ML Model**: OpenAI Whisper
- **Environment**: Google Colab / Linux (Pop!_OS)
- **Libraries**: `whisper`, `ffmpeg`, `pytube` / `yt-dlp`
